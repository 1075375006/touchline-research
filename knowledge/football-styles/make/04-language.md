# 04 语气节奏与转场

语速说明：系统建议值为每字/每分钟240，这是可编辑的默认设置，并非对作者真实语速的测量；没有音频证据时不宣称掌握其语速。

整体语气：口语、直给、短句为主，像在跟人当面拆一盘棋，而不是念报告。常以第二人称拉近距离（“今天不要轻视某队”“这不是一边倒的比赛”），用一连串反问推进（“某队怕什么？”“某队来客场踢球不就是四个字吗？”），反问之后立刻给出作者自己的答案。

转场的两种把手：一是“但”——先承认对方利好，立刻翻转；二是“所以问题就变成”——把比赛性质重新定义，把注意力从“谁强”移到“谁能把悬念留住/谁会被迫变形”。两段之间常用“问题由此转为……”完成换挡。

收尾方式：分两类。明确方向稿用一句可检验的断言收束（“所以我认为某队至少不败”），不加互动；带情绪的稿用“复制粘贴就行”“主场氛围就会土崩瓦解”这种高确定性短句；而隐式方向稿则停在“握手言欢”“今天很难开心”这类模糊但方向偏窄的表述上，不明说胜平负。

用词习惯：大量使用“纠错”“收割状态”“破大巴”“防守漏勺”“帮倒忙”这类形象词，数字常以“多少次”“百分之多少”口语化带出。译名存在混用与不稳定（同一队出现两种写法），调用时应统一译名并标注为待核验。

节奏结构：通常是“背景一两句 → 反转一句 → 功能清点若干句 → 对接一到两句 → 反证一句 → 收束一句”。段落短，转折密，几乎不做长篇铺陈。调用时保留这种密转折、短收束的节奏即可，不要照搬任何完整原句，也不复制作者身份或战绩表述。
