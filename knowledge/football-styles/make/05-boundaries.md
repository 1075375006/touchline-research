# 05 反证、跳步与无方向分支

反证的四种处理方式在本作者稿件中反复出现：①被承认后缩小主张（承认对手创造力强、机会多，但只推到“终结不稳”，不否定其进攻）；②被条件化（承认本菲卡赛季初有问题，用“回到主场立刻回应”限定）；③被具体回应（剔除红牌污染的样本后再评价球队）；④被话术消解（用反问“恐怕已经晚了一轮”压低对手反击可能，这属于未认真论证，调用时应补足证据或明确标注为弱处理）。可调用模板必须保留最强反证，并写清它何时足以改变结论。

必须隔离的跳步：
- 把短窗口爆发当可复制（“十七分钟打花→次回合复制粘贴”），属于样本外推，调用时须加“阵型空档稳定存在、对手无法调整”的前提，否则降级为“存在可能”。
- 把“快速纠错”当必然能力，调用时改为条件句（“若该队能在本场重现纠错，则……”）。
- 把门将或前锋的超常发挥当稳定预期，必须写清是“若重现”，不是“必然”。
- 把历史交锋“连续几次没输”规律化，只有当能说清机制时才引用，否则不作证据。
- 把“保级队为奖金拼命”当必然，也属跳步。

必须拒绝认证为事实的内容：主办方利益、所谓剧本、心理必然、球队“真实意图”。利益与需求只能解释“选择空间”，不能证明结果被操控；“值得关注”不等于“支持”。

无方向分支的处理：
- 看点稿：问题→双方各自可行路径→关键对位或观察点→开放问题，结尾不写倾向；以互动问句结尾不自动等于暗示胜负。
- 复盘稿：关键转折→当时可见的选择→连锁后果→有边界的解释，禁止用赛后信息伪装赛前预测。
- 知识稿：常见疑问→定义/规则→可核对例子→适用边界。
- 叙事稿：处境→真实选择→变化与代价→主题，不虚构对话、心理或现场。
- 资讯稿：按统一维度归类→比较差异→说明看什么，材料不足时不追加胜负倾向。

争议机制的描述与约束：条件翻转本作者用得很重，但把“满场氛围”“必须拿分”一律读成负担有过度解释风险，调用时应至少给出一条“它其实利好”的反面材料再翻转，否则退回普通对位。
