# 03 原稿公开论证案例

说明：本作者本地可分析样本共6条，含正文4条、图文1条、缺失1条。下面覆盖全部可用样本，其中1条为无方向的非足球内容、1条为无法提取正文的缺失样本，均按原样呈现，不硬解成赛果倾向。

案例1（recordId make-d6afdbdef2d6，挪超斯达vs维京，明确方向）：前提——门票售罄、四大主场自零七年以来第一次满场，常规解读是保级队获得额外能量；本赛季六个联赛主场一胜三平二负、进六丢十。中间判断——满场反而帮倒忙，因为球迷与俱乐部要求斯达主动出击，而保级队本该靠身体和反击缩小差距，等于把它推离舒适形态。关键转折——检验进攻能力后发现终结为零（中锋身高一米九三但预期进球偏低、把握差；边锋多次射门却零球零助攻），于是被期待压上只会掉进维京节奏。终点——维京多点进攻首回合十七分钟打花对手，次回合“复制粘贴就行”，主场氛围土崩瓦解。反证处理——承认德比氛围与半场三比一领先，但用主场战绩差、终结为零、防线无法同时处理三件事否定；未处理维京轻敌或客场波动。可复用部分：条件翻转 + 终结效率核查 + 多点进攻的复制性假设（调用时须加“对手无法调整”的前提）。

案例2（recordId make-86ee01778d1a，巴西杯巴拉纳竞技vs维多利亚，明确方向“至少不败”）：前提——两回合制，巴拉纳想在主场提前终结。中间判断——大比分惨败有两张红牌因素，须剔除该样本；巴拉纳真正问题是不会破密集防守，创造机会排第一但浪费也排第一，且得分过于依赖单一球员（占比四成多）。关键转折——把对手“唯一得分点被包夹”与“门将抗压”对接，再叠加动力差（巴拉纳是老油条、维多利亚需要奖金与晋级路径）。终点——维多利亚至少不败。反证处理——承认对手创造力强、机会多，但用终结不稳、单点被限制覆盖；未深入论证维多利亚自身能否进球。可复用部分：剔除污染样本的资格、创造与把握分离、功能缺口对接、动力差作为修正项。

案例3（recordId make-0c14b685c8ef，挪超莫尔德vs萨普斯堡，隐式方向“不是一边倒”）：前提——莫尔德距欧战区两分、营收下滑、首要目标是回欧战；萨普斯堡财力有限、压力更小。中间判断——换帅后莫尔德进攻数据上涨但防守丢了七次，是拿防守换进攻，下半场体力会放大弱点。关键转折——对手低控球、长传和传中不减少，倾向越过中场找前锋与边路，正好利用莫尔德压上后的身后空档；再用首回合边路牵制和历史样本佐证。终点——上下握手言欢，实质指向莫尔德难以轻松取胜。反证处理——承认莫尔德重回正轨、控球占优、有主场动力，但只否定“一边倒”，没有否定其进球能力。可复用部分：用换帅得失做持续性判断、低控球队伍利用空间的机制、隐式方向如何收束。

案例4（recordId make-066ef16d1ac8，欧联杯资格赛本菲卡vs哈茨，明确方向）：前提——本菲卡满状态并完成一轮纠错，哈茨失去主帅、射手与中场核心。中间判断——不只是名气差距，而是适配度差距；资格赛考验遇到问题后能否快速调整。关键转折——引入关键前锋进入收割状态并拉长到三个赛季的稳定输出，同时指出哈茨缺最后处理人、定位球失守、下半场开局走神。终点——本菲卡应先主后客，在光明球场解决悬念，否则客场面对更多身体对抗与意外。反证处理——承认本菲卡赛季初存在衔接问题、首回合也丢球，用“回到主场立刻回应”化解；哈茨利用磨合期制造冷空气的可能被反问压低，未认真论证。可复用部分：功能丧失的叠加、把“纠错”当成需要验证的能力而非必然（此处原稿偏乐观，调用时应降级为条件）。

案例5（recordId make-7cb5c4b028b2，图文非足球，无方向）：前提——把“命”定义为性格驱动的重复结局。中间判断——把“运”定义为对惯性的主动偏离（该走小路却走大路、该放弃却坚持）。关键转折——用对仗比喻把两者对立：命是重复死循环，运是突然急转弯。终点——性格不改命就不会改，性格一变命运立刻改变。反证处理——完全未处理环境、资源与偶然性，也未讨论性格是否可轻易改变。可复用部分：只借“先定义、再对仗、后收断句”的修辞结构，不得迁移“性格决定命运”这一实质主张，也不得用于球队方向。
