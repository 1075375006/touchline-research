# 05 反证、跳步与无方向分支

原稿争议机制要描述清楚，但调用时必须约束。

一，占位阻断：标题、ID、“字幕已提取”等占位不产出方向，只能记 missing/unavailable。调用时：材料只有标题就写“材料不足”。

二，声明不预测却实质给向：原稿常见“不掺杂预测”与逐场胜负并存。调用时：要么删逐场胜负，要么标 explicit 并承认方向；不能既免责又给结论。

三，概率/赔率/热区跳步：概率、赔率、热区、超算百分比若无来源和口径，不能从数字直接跳到赛果。调用时：标来源、样本、模型未纳入变量；概率只作不确定性压缩，不替代执行层证据。

四，玄学、命硬、魔咒替代因果：只作心理变量或小样本关注点，不能当因果。调用时：若要改变方向，必须补可核对的行为、阵容或战术证据。

五，动机指认、派系、人情、假球暗示：不能将主观心态、主办方利益、所谓剧本认证为事实。调用时：写成“外界传闻/需核实/利益约束”，并说明利益与需要不能证明真实意图，更不能证明操控结果。

六，单场外推与跳步归因：一场大胜不能直接等于一代人希望，一个商业现象不能直接等于赛制设计。调用时：限制样本，补对手水平、后续赛程、可复制性反证。

七，译名数据错漏仍作论据：错漏材料不能当证据。调用时：先核对，无法核对则不用。

八，同材料正反两用：同一事实不能一边作利好一边作利空。调用时：固定权重，说明哪一方更重。

九，裁判历史/纪录当赛果吉兆：只作背景，不作吉兆。调用时：裁判尺度只影响具体环节。

十，热区/球迷热度/超算无来源：无来源则不用，或只写“有讨论热度”。

无方向分支：看点稿=问题→双方路径→关键对位→开放问题；复盘稿=关键转折→当时可见选择→连锁后果→有边界解释；知识稿=常见疑问→定义/规则→可核对例子→适用边界；叙事稿=处境→真实选择→变化与代价→主题；资讯稿=统一维度归类→比较差异→说明看什么。材料不足、声明不预测、非足球、占位样本，一律不得硬解成赛果倾向。对位和数据比较是分析工具，不等于验证了结论。
