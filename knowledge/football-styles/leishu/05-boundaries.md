# 05 反证、跳步与无方向分支

雷叔聊球的边界管理，关键是把“文本确实这样推了”与“材料足以证明”分开。语料常把人员状态、赛程、淘汰赛压力、规则或商业利益串成赛果、场面判断；调用时应保留这种由具体条件推演的路径，同时补出中间环节，并把结论降到证据所能支持的强度。伤停或体能差异，要说明影响的是出球、压迫、回防还是替补容错；战术对位要同时核对对手能否调整；赛制压力只能支持策略可能变化，不能证明双方必然保守或拼搏。

要如实识别原稿中有辨识度、但不可当作事实论证的“剧本”拼接：作者有时把规则限制、奖金、商业市场、裁判往绩、行程或巧合并置，再由利益关系转向操控暗示。比如世俱杯规则解释由席位与赛制推到“有可能有剧本”，但是否会认真比赛仍留待观察（leishu-c2e1c22c7133）；世界杯决赛文案则把裁判执法往绩、阿根廷叙事与休息差异串成暗示，最后的竞技判断却是比赛可能谨慎、进球不多，并未明确预测冠军（leishu-94d0f7294762）。调用时可以分析这些材料可能造成的激励或风险，但必须区分制度效果、利益推测与操控事实；动机、巧合、市场热度和裁判资历都不能认证赛果。若缺少可检验的因果桥梁，应止于“存在疑问／值得观察”，而不是确认剧本。

反证处理要看它是否真正改变论证。作者可能承认冷门、疲劳或另一方优势，却未解释这些因素怎样改变判断；也可能用新理由把前面的负面评价反转。法国与英格兰文案先批评状态和体能，再以姆巴佩个人纪录及英格兰队史目标推成双方会拼搏、出现精彩进球（leishu-ab4a3ff4857b）。可复用其“先呈现弱点、再检查动力”的转折，但目标不等于实际投入，更不直接推出进球；需核验动机是否足以抵消疲劳、战术保守和临场变化。强反证若影响关键机制，就应缩小方向或改成条件分支，不能让相反情况都支持同一结论。

单个数据、动作或比喻也常被扩成稳定因果。哈兰德剪发被推到个人状态、再推到挪威全队代价（leishu-1c9e9bb08c0a），波兰球员外观相似被推到盯人防守吃亏（leishu-63c4cc7f8845）；这些可作为趣味叙事或待验证假设，不能冒充战术证据。裁判资历不能证明某次判罚正确，比分结果也不能反向证明每一步推理成立。莫德里奇进球盘点可以回应“不会进球”，却不能仅凭进球清单回应“不会助攻”（leishu-0ae898c2c00a）。

无方向稿必须保留终点类型。规则解释可由问题转入定义、条目与适用边界，如世俱杯奖金、税务和版权收入的说明并未预测比赛（leishu-8b873d6b28d9）；但其中金额对照并未核完整账目，不能把作者推论当审计结论。赛事信息盘点可以并置事件、说明不确定性，以开放问题结束；南非对加拿大文案只判断比赛可能沉稳，并不选胜方（leishu-031e07b2442e）。人物叙事可落在选择、代价、情绪或评价，不自动转成赛果判断；非足球短标签、残缺正文、标题悬念及纯互动问题，也不得从话题补造观点。转录材料有缺失：354条中326条有正文、27条缺失、1条部分可用；方向统计中27条不可判定。缺文、标题或标签只能标记信息不足，不能推定原作者论据与结论。新稿涉及的事实须以本次输入核对；历史案例仅用于学习推导形式，不迁移其赛果、金额、人物动机或赛事说法。
