# 足球博主风格知识库

整理日期：2026-09-30。来源仅为本项目的「足球文案库」。

## 整理目标

学习作者公开文案如何组织材料、建立前提、改变观众判断，最后抵达方向或观点。口头禅、语气和长短句只作辅助特征。既保留作者原本的写法，也写清新稿可安全复用的论证机制；不把说服力直接当成事实可信度。

## 两层资料

1. **逐篇研究档案**：每位作者目录的 corpus.jsonl 保存原文、文件位置、行号与 SHA-256；analyses.jsonl 保存逐篇论证拆解。相同视频的不同版本保留，原文缺失与占位单列，不能补写未获得的字幕。
2. **可调用知识库**：每位作者的 style.json 保存角色提示词和独立知识条目。角色不冒充作者本人，知识只提供结构与表达。对应条目导入应用的「口播写作 → 风格与知识库」。单条不超过 10000 字符、单风格启用总量不超过 20000 字符。

## 阅读与证据标准

- 逐篇全文通过项目中已配置的分析模型处理；其中三条短文另作直接全文编辑校核，另补核三个缺失的风险字段，均单独留痕；原文全部传入，有输入哈希与处理回执；原文短锚点逐字验证。另作结构、覆盖率和代表案例核对。
- 所有「事实」只表示原稿声称，未另行做足球事实核验。字幕里的人名误识别、日期冲突、错误数字与未经核验的动机推断不得迁移到新稿。
- 不能把文件标题中的「全部」或「90个」当成真实篇数；以实际可分篇内容为准。视频ID索引与元数据单独用于核对，不当作已获得正文。
- 缺字幕、只留标题、声称已提取但没有实际文本，均不计为读过完整文案；保留可追溯的缺失清单。
- 分析原文中的利害关系、战意或所谓剧本，是分析作者的论证动作，不代表认证其真实性。

## 统一调用方式

选择一种主风格；输入本次研究材料、目标受众、稿件类型、时长，以及待检验的方向或问题。若没有方向，明确要求开放式看点、复盘或解释稿。角色提示词必须先判断本次材料适合哪条机制，再组织正文。

调用变量：

- 主题/对阵：本次讨论对象；
- 稿件类型：赛前判断、赛后复盘、知识解释、人物/球队叙事、资讯盘点；
- 方向：待检验假设，或「无预设方向」；
- 已核验材料：事实与出处、时间、条件、冲突；
- 最强反证：对主判断最不利的信息；
- 输出：口播稿长度与语速、是否附简短结构说明。

源稿有确定方向但本场证据不足时，保留它的问题设置与组织方法，降低结论强度或改成无方向模式。不要为了像某位作者而补造理由。
