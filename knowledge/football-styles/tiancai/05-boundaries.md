# 05 反证、跳步与无方向分支

本节处理该账号最需要约束的部分：哪些机制可以保留描述，但调用时必须加条件。

### 一 反证的五种处理方式
1 承认并缩小主张：可用。写法是「对手X占优这一点成立，所以本文只判断 {{较弱结论}}」。
2 条件化：可用。写法是「若 {{条件A}}，则维持；若 {{条件B}}，则改为 {{另一结论}}」。
3 具体回应：可用。要给出执行者、位置、方式与代价。
4 话术消解：原稿常见，把不利数据说成「反而更难得」。调用时禁用，除非另给独立机制说明为什么不利会转成有利。
5 忽略：禁用。每篇至少正面写一次最强反证。

### 二 原稿中的跳步清单与修复约束
跳步一 由身价、阵容深度、旅欧人数直接推出取胜、晋级、夺冠概率。修复：身价只能作为入口，必须补一条过程材料（该环节谁执行、对手如何应对），才能影响判断。
跳步二 把未来赛事当作已发生事实叙述。修复：未发生的赛程、比分、纪录必须标为假设或预测场景，不得用完成时叙述。
跳步三 把未核验的转会、伤停、红牌、退役、最后一届当既定事实。修复：列为待核验变量，并说明它若不成立会怎样改变结论。
跳步四 用单方叙述推测裁判或球队动机。修复：只描述可观察的判罚与结果，不推断动机。
跳步五 同一场比赛在不同篇重复同一套文本与判断。修复：同题材只写一篇，重复即视为无新内容。
跳步六 混合标准的绝对排名。修复：开头声明维度，并承认主观性。
跳步七 以类比替代产品验证。修复：标明商业属性，产品结论需独立来源。

### 三 无方向分支的四种写法
看点稿：核心问题 → 双方可行路径 → 关键对位 → 观察点 → 开放问题。
复盘稿：关键转折 → 当时可见的选择 → 连锁后果 → 有边界的解释；不使用赛后信息伪装赛前预测。
知识稿：常见疑问 → 定义与规则 → 可核对例子 → 适用边界。
叙事稿：处境 → 真实选择 → 变化与代价 → 主题；不虚构对话、心理与现场。
资讯稿：统一维度归类 → 比较差异 → 说明看什么；材料不足时不追加倾向。

### 四 争议机制的保留与约束
原稿确实存在「先给强结论再找理由」「用身价单因推概率」「结尾提问代替方向」「标题预示预测但正文只做盘点」「广告未标明」。这些机制在描述层面要如实写出，在调用层面加约束：强结论必须在正文被材料兑现；单因推断必须补过程材料；方向稿要给出方向与翻转条件；标题与正文的承诺必须一致；商业内容必须在开头声明。

### 五 不可越界的表述
不把主观心态、更衣室氛围、主办方利益、所谓剧本、裁判动机、名人偶遇真实性认证为事实。对位与数据比较是分析工具，不等于结论已被验证。可以把这些写为「待核验」「若成立」或直接略去。

### 六 强度自检表
材料只有身价与近况 → 落点到场面或环节，不落胜负。
材料有具体执行路径与对手应对 → 可落强度分级。
材料有完整因果链 → 可落复盘解释。
材料只有公开行为 → 可落价值判断，但须标注为主观评价。
