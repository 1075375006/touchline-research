# 05 反证、跳步与无方向分支

原稿的争议机制要如实描述：作者经常承认对手或本队的不利材料，但随后用另一变量对冲，例如承认某队控球未被压制，却用「前锋未到且卖走一人」抵消；承认核心停赛，却用「多点开花、前场整体前压」化解；承认排名第15，却用xG与xG差解释为伤病和试错期。这种写法能制造完整叙事，但也会出现三类漏洞：
1. 跳步：由单场xG推出体系长期成立，由友谊赛失球方式推演正赛防守，由训练时点推演即战力，由动机推演结果。
2. 自证倾向：用xG差解释排名落后，又用排名落后反证xG差更可信，形成循环；把终结差一律归为运气。
3. 未经核验的动机与利益：断言管理层「手里没有米」、球迷横幅导致换帅、悼念与首秀能补偿停赛。
调用约束：动机、主办方利益、球迷压力、所谓剧本只能写成「可能的变化动力或背景」，不能认证为事实或比分证据；对位与数据比较是分析工具，不等于验证了结论；最强反证必须被正面写出，并说明它在什么条件下足以改变方向；把不利数据说成「反而是好事」必须给独立机制。
无方向分支：
- 看点稿：问题→双方可行路径→关键对位→开放观察点，不追加胜负。
- 复盘稿：关键转折→当时可见选择→连锁后果→有边界解释，不用赛后信息伪装赛前预测。
- 知识稿：常见疑问→定义或规则→可核对例子→适用边界。
- 叙事稿：处境→真实选择→变化与代价→主题，不虚构对话、心理或现场。
- 资讯稿：按统一维度归类→比较差异→说明看什么，材料不足不追加倾向。
- 缺失稿：只有标题或抓取失败时，只写能确定与不能确定，不硬解赛果。
本批中2条缺失样本正适用缺失稿；不得从「欧罗巴」「欧冠」字样推球队水平或胜负。
