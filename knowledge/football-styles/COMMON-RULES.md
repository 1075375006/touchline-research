# 共用论证与调用规则

## 先判定作者究竟在表达什么

区分「谁赢」「谁不败」「谁晋级」「比赛是否开放」「谁更可能掌握节奏」「为何发生这个结果」「人物/球队价值判断」以及「只介绍信息」。这些终点不能互换：占据主动不等于获胜，值得关注不等于支持，晋级优势不等于90分钟胜出。免责声明说不预测，也可能在正文中形成明确方向；以实质内容判定。反过来，以互动问题结尾也不自动代表暗示胜负。

## 逐步拆解的最小单位

每一步记录：原稿给出什么材料 → 用什么比较、因果或类比把材料连接起来 → 形成什么中间判断 → 如何为下一步服务。标明是作者明确讲出还是分析者重建的隐含前提。原文先给结论再找理由时，忠实记录其呈现顺序，不美化成逐层发现结论。

## 六种可复用的公开推导动作

1. **拆指标**：比分/排名/身价只是入口 → 分离结果与过程 → 找到可重复的形成机制 → 判断本场能否再现。必须有具体过程材料，不能只用漂亮话推翻指标。
2. **换条件**：承认某结论在条件A成立 → 指出本场条件B不同 → 说明受影响的具体环节 → 调整判断。不能仅说「今时不同往日」。
3. **做对位**：本方长处与对手短处都具备证据 → 解释相遇时怎样产生机会或代价 → 检查对手修正能力 → 推出有条件的场面判断。
4. **比持续性**：双方都有得分路径 → 比较哪条路径更容易反复发生、代价更低、替补与容错更强 → 给出倾向。不要用单一进球直接证明整套体系。
5. **用约束解释选择**：赛制、比分、体能或资源约束 → 可选策略发生什么变化 → 每个选择有什么代价 → 推出条件分支。利益与需要不能证明真实意图，更不能证明操控结果。
6. **由具体上升为观点**：一组动作或事件 → 稳定特征 → 更广泛的人物/球队解释。限定例子的代表性，不能把情绪高潮当作因果证据。

## 保留反证的方式

分别记录反证被承认并缩小主张、被条件化、被具体回应、被话术消解，还是被忽略。可调用模板应保留最强反证，解释它何时足以改变观点。把不利数据说成「反而是好事」必须提供独立的机制支持。

## 无方向分支

- 看点稿：问题 → 双方各自的可行路径 → 关键对位/观察点 → 开放问题。
- 复盘稿：关键转折 → 当时可见的选择 → 连锁后果 → 有边界的解释；不使用赛后信息伪装赛前预测。
- 知识稿：常见疑问 → 定义/规则 → 可核对例子 → 适用边界。
- 叙事稿：处境 → 真实选择 → 变化与代价 → 主题；不虚构对话、心理或现场。
- 资讯稿：按统一维度归类 → 比较差异 → 说明看什么；材料不足时不追加胜负倾向。

## 写稿前自检

最关键的两次「所以」是否有实际桥梁？多条理由是否只是同一事实换个说法？最强反证是否被正面处理？观点强度有没有超过材料？如果删去博主姓名和口头禅，结构还是否体现该风格？
