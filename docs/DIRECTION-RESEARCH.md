# 1.1.4 全阶段围绕用户方向取证

用户给定的研究方向是每个阶段的取证目标。规划、搜索、补搜、证据整理、综合报告和口播都围绕该方向展开，而不是只在报告末尾补一句结论。

## 每阶段执行

1. 拆解方向在本阶段成立所需的可核实条件，例如防线可用人员、同类对手表现、对位机制或实际休息间隔。
2. 至少一条 support 查询寻找支持事实，一条不同的 corroboration 查询寻找独立来源或不同类型的数据佐证；可附加 verification 核对必要条件。
3. 查询使用球队、明确日期和具体事实关键词，记录 reason、purpose、supportAngle。supportAngle 是待查目标，不是已证实事实。
4. 读取原文后解释真实事实如何支持方向，并保留引语、来源、时效、置信度、限制和 directionReason。
5. 审计重点检查支持链条缺什么、还缺哪些独立佐证。补搜优先缺失的支持事实，其次独立佐证；不再默认寻找最强反例。
6. 通过连续摘录核对、来源绑定和逐条语义审核后入库。已发现的矛盾、重复转载、中性材料和未知不能强行改写为支持。

这套规则覆盖核验全景、近期逐场、实力数据、经营内部稳定、战术、阵容伤停、体能旅行、赛制动机、教练、磨合、外部因素、裁判 VAR 全部十二阶段。近期比赛仍使用完整样本，不隐藏不利场次。

## 报告和后台

- 查询记录展示寻找支持证据、补充独立佐证或核验支持条件，以及本次支持切口。
- 新证据展示与用户方向的关系；旧证据缺少该字段时保持正常显示。
- 报告优先组织支持事实、独立佐证和本场机制，反证作为已知风险保留。证据不足则写明无法支持，不凑因果链。
- 口播门槛为有效支持材料、至少三条有证据绑定的因果链及两个来源域名。不再要求必须先找到反方事实；两个域名也不自动等于两个独立事实。

## 旧任务与预算

新任务全流程使用新规则。未完成或由用户重新打开的旧阶段会归档此前计划与分析并重新规划，复用已取得的搜索、原文和逐场资料；累计预算不清零。归档保存在 previousDirectionPasses，新检查点标记 directionPolicyVersion=1。

已闭合阶段和已有报告不会自动改写或重跑。旧任务页面会提示历史结果的版本边界；要完整按新方向策略研究，可新建任务，或在赛前对允许重开的阶段执行重试。每阶段至少两条初始查询意味着搜索量可能高于旧策略，仍遵守用户配置的查询和模型调用预算。

本次验证范围见 [VERIFICATION.md](VERIFICATION.md)。
